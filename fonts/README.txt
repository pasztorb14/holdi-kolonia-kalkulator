Self-hosted UI fonts for the Holdi kolónia-kalkulátor v0.8.0 HUD theme.

- Barlow Condensed (weights 400, 500, 600, 700; latin + latin-ext)
  SIL Open Font License 1.1 — see BarlowCondensed-OFL.txt
  latin-ext includes Hungarian ő/ű (U+0150, U+0151, U+0170, U+0171).

- Share Tech Mono (weight 400; latin)
  SIL Open Font License 1.1 — see ShareTechMono-OFL.txt
  Used for small monospaced readouts and index numbers.

These files are also inlined as base64 woff2 in index.html (@font-face).
